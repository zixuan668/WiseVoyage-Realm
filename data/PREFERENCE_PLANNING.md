# 颐和园景点与偏好规划

景点由 6 个扩为 16 个。新增：乐寿堂、玉澜堂、排云殿、谐趣园、石舫、玉带桥、南湖岛、铜牛、德和园、文昌阁。

## 可追溯数据

- `summer_palace_locations.json`：WGS84 点位及逐点来源。原六点 ID 和已校准点位不变；昆明湖采用知春亭观景点，南湖岛采用涵虚堂观景点。
- `summer_palace_profiles.json`：历史、自然、摄影、亲子四类特色的人工标注强度（0–5）、具体观察依据、台阶提示。不是用户行为模型或热度数据。
- `summer_palace_walk_distances.json`：2026-10-10 OpenStreetMap 路网快照的园内步行最短距离。1165 个连通道路节点；每个景点关联最近步道，并计入接入距离。不使用船渡，不直接跨湖连线。OSM 数据遵循 ODbL。
- 景点文字依据：[北京市公园管理中心颐和园介绍](https://gygl.beijing.gov.cn/mlgy/mlgy_lsmy/201911/t20191129_732237.html)。开放、票务和实际道路状况以园内公告为准。

## 规则

兴趣可多选；综合与具体兴趣互斥。按特色强度评分，优先兼顾尚未覆盖的兴趣，评估插入不同游览位置后的增量时间，再选择可行的景点组合。最多八站，不以全量勾选代替推荐。

预算包含建议停留、逐段步行取整和休息缓冲。正常速度假设为 75 米/分钟，休息为停留加步行的 8%；轻松或亲子为 55 米/分钟、15%。亲子和轻松方案排除标注台阶较多的景点，但不保证中间道路完全无台阶或满足无障碍标准。时间不包含离园、排队、临时闭路和船渡。

出发区域使用对应景点的道路接入位置（东部仁寿殿、北部苏州街、南部铜牛），不是精确园门位置。自动模式从所选首站开始计时。其他城市只在同城数据内推荐，缺少路网时明确注明近似距离。

自然语言入口与偏好按钮共用同一规划器，消息中明确的时间、区域和慢走要求覆盖页面选项。若配置大模型，仅让其解释已验证行程，不允许覆盖景点顺序或总时长；服务失败或解释校验不通过时回退本地说明。逐点展示匹配理由，修改条件后网页要求重新生成，小程序清除旧方案。

## 数据导入与验证

在仓库根目录运行 `python scripts/expand_summer_palace.py`，幂等新增十处景点并登记知识文档，不重置原景点、路线或数字人。需要本机已配置的数据库环境。

路网生成脚本 `scripts/build_palace_catalog.py` 使用保存在 `work_dirs/palace-expanded-osm.json` 的 OSM map API 快照。生成前检查原六个坐标来源，保留高德底图校准值。

后端测试：`python -m unittest discover -s scripts/tests -p test_preference_planner.py`。覆盖不同偏好、预算含步行休息、亲子台阶避让、跨湖道路距离、城市约束和自然语言解析。
