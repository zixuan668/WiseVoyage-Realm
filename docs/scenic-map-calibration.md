# 颐和园地图范围与点位校准

2026-10-12：网页规划页使用实际 16 个景点的范围作为全景视野，取消原来的 20% 扩边和整级缩放。支持 0.25 级缩放，四周各留 20px 给标记；缩小下限根据容器大小计算，拖动范围限制在景点范围附近。该矩形是地图展示范围，不是官方景区行政边界。选择景点放大至 18 级，点击“景区全景”返回；窗口变化时重新计算缩放下限，选择景点和切换语言不重置视野。

## 坐标来源与锚点

规范数据是 `data/summer_palace_locations.json`。数据库统一保存 WGS84，高德底图展示前仅转换一次至 GCJ02。数据逐点记录来源、实际锚点、GCJ02 校准坐标，以及对应的 18 级瓦片和像素位置。

- 仁寿殿、长廊、佛香阁、排云殿、德和园、石舫、文昌阁对照高德公开同名 POI，并在当前底图上复核。
- 乐寿堂、玉澜堂、铜牛等对齐底图地标符号；谐趣园从区域平均点（水面）移至宫门入口。
- 昆明湖定位在知春亭观景点，南湖岛定位在北侧观景点；面状景观不使用游客无法到达的区域平均点。
- 玉带桥、十七孔桥使用桥面节点；苏州街使用长桥北侧入口，避免把文字标签或水面作为游客目的地。

标记外框固定 28px，锚点固定 `[14,14]`，内圆使用 `border-box` 并居中。选择状态不移动锚点、不动画改变尺寸，消除边框和尺寸变化产生的视觉偏移。

坐标与位置说明已包含在当前颐和园内容包中；新环境按根目录 README 导入，后台仍可按实际现场信息维护。

## 验证与精度边界

坐标测试覆盖 16 个点的正逆变换、瓦片投影和公开 POI；组件测试覆盖全景范围、选择状态锚点、18 级定位与窄屏适配。浏览器在 18 级实际读取标记中心及瓦片的屏幕几何，16 个标记相对校准坐标的渲染偏差均小于 1px（Leaflet 整像素取整）。这证明展示对齐，不代表实地 GPS 测绘精度；底图符号、地形表达和公众 POI 本身仍有数据精度限制。
