# 园内步行路线与剩余行程调整

适用网页游客导览。当前支持颐和园16个景点与东宫门、北宫门、新建宫门三个实际出入口。

## 路径与距离

`data/summer_palace_walk_network.json` 是2026-10-16导出的 OpenStreetMap 园内步行图，包含1188个节点、1270条边。来源和版本哈希保存在文件内，许可为 ODbL 1.0；地图界面保留 © OpenStreetMap contributors 署名与许可链接。来源：https://api.openstreetmap.org/api/0.6/map?bbox=116.245,39.979,116.281,40.004 。

构建器仅保留颐和园边界内允许步行的现有道路，排除已标注禁止通行、施工及围墙等路段。桥梁、台阶和原始way ID保留。当前快照没有单向步行标记，路网按双向步行处理；更新数据时须重新核查通行规则。

景点展示坐标与步道接入点分开。接入点只投影到已有道路并拆分该道路，不凭空补连接边。16个点位的接入偏移约0—34米；该数值表示资料坐标到道路的距离，不代表实测定位精度。坐标使用WGS84，绘制到当前地图底图时统一转为GCJ-02一次。

每一段路径由Dijkstra沿同一组道路边计算，距离、时间和地图折线共用结果。不存在连通路线时返回不可用，不画景点间直线，也不返回零米冒充成功。普通概览和个性化规划使用同一路网；离园距离实际计算到所选门，不再使用景点代替门或任意固定时间。

## 调整行为

- 时间不够、想少走路、跳过下一站、准备离园四种目标。只有时间目标必须提供时限。
- 已完成前缀和当前景点锁定。未来景点可设置必游、跳过、允许重排和避开已标注台阶。
- 最多提供两套不同方案：保留重点和减少步行。少走路方案设覆盖下限，防止把景点全部删掉作为最优结果。必游不可达或预算不足时明确失败。
- 未来景点不超过12个时使用完整状态搜索；更大集合使用有界搜索，结果不宣称全局最优。
- 预览显示调整前后道路、路段距离、行程顺序、删除原因与时间组成。采用前只读，改变条件后必须重新计算。
- 每套方案独立签名，10分钟有效。采用时校验会话权限、路线版本、当前进度、路网版本和剩余时间，重新计算后写入；过期、重放或旧进度均拒绝。
- 更新同一会话的路线，不更换数字人或清空聊天。剩余路线概览保留选定出口。

## 更新与临时封路

先保存来源XML到 `work_dirs/summer-palace-osm.xml`，运行：

```powershell
.venv/Scripts/python.exe scripts/build_scenic_walk_network.py --osm work_dirs/summer-palace-osm.xml --date 2026-10-16
```

维护者可将临时关闭道路的原始OSM way ID加入 `data/summer_palace_walk_rules.json` 的 `blocked_way_ids`。该规则作用于后续查询并使旧预览失效，重新开放时移除对应ID。修改构建出的路网文件需要重启后端。当前没有管理界面自动维护封路，也没有接入实时开放/客流/天气封路数据。

避台阶仅依据快照中的台阶标记，不等于无障碍认证；道路、建筑入内、票务及门区实际开放以现场为准。当前景点停留时间、步速和休息比例都是可解释估算，不是实时步行导航。

## 验收

后端测试覆盖全部256组景点配对、沿源道路边还原几何、湖岸绕行、桥梁关闭、不连通、避台阶、真实门点、必游约束、进度锁定、独立方案签名、重放和旧方案拒绝。前端覆盖道路几何不回退直线、条件修改、迟到响应、替代方案签名、到期、预览后确认及原有导览流程。

实际浏览器验收行程：仁寿殿→铜牛→石舫→谐趣园→昆明湖→十七孔桥→东宫门。原剩余步行6666米；保留全部后续景点重排后4955米，少走路方案2987米（减少一个后续景点）。截图位于忽略目录work_dirs/walking-route-before.png与walking-route-after.png。
