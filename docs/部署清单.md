# 部署清单（新电脑 / 新服务器）

面向「克隆仓库后完整跑起来」的检查表。数据库和密钥不在 Git 里，需要本机单独配置。

## 1. 必须配置 `.env`

把根目录 `.env.example` 复制为 `.env` 后填写：

| 配置项 | 用途 | 缺失的后果 |
|---|---|---|
| `POSTGRES_SERVER / PORT / USER / PASSWORD / DB` | 数据库连接 | 后端无法启动 |
| `ADMIN_USERNAME / ADMIN_PASSWORD` | 首次启动创建管理员 | 管理端无法登录 |
| `TOKEN_JWT_SECURITY_KEY` | 登录令牌与外部凭据加密 | 登录失效；星云密钥无法解密 |

## 2. 内容与数据（按顺序）

1. 启动一次后端，让数据表自动创建；
2. 解压 `resources/summer-palace-content.zip`，执行 `python scripts/import_resource_pack.py 解压目录`（16 个景点、3 条路线、2 个数字人、24 份知识文档）；
3. 执行 `python scripts/seed_scenic_audio.py`（自动读 `.env`，补齐 16 条讲解记录，删除测试景点「智远楼」）；
4. 执行 `python scripts/verify_scenic_audio.py` 验证讲解记录和音频文件对应。

## 3. 可选密钥与功能降级

| 配置项 | 控制的功能 | 不配置时的表现 |
|---|---|---|
| `LLM_API_KEY / LLM_API_BASE / LLM_MODEL_NAME` | 数字人问答、口语化回答、英文回答 | 问答退回本地知识库原文，能答但更“档案化” |
| 星云数字人应用（管理端绑定） | 数字人形象、实时语音 | 数字人显示「暂时无法连接」；讲解音频仍可播放（bundled-recording） |
| `VISION_API_KEY / VISION_API_BASE / VISION_MODEL` | 拍照识景 | 识图不可用 |
| `SMTP_*` | 邮箱注册、验证码 | 只能使用已有账号登录 |
| `PUBLIC_SERVER_ORIGIN` / 局域网地址 | App 扫码领取路线 | 手机无法领取网页端方案 |

## 4. 启动

1. 后端：`python -m uvicorn server.base.base_server:app --host 0.0.0.0 --port 18000`；
2. 网页端：`frontend` 目录下安装依赖后启动；
3. App：用 HBuilderX 导入 `app` 运行到手机基座，手机与电脑保持同一网络（或 USB 反向转发 18000）。

## 5. 安全

- `.env` 含数据库密码和平台密钥，**不要提交 Git、不要公开发送**；
- 需要共享外部平台能力时，申请一份低额度、可撤销的密钥单独提供；
- 部署完成后及时修改管理员初始密码。
