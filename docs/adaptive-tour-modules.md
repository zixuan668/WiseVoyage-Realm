# 网页导览的三项增强

实现日期：2026-10-13。两个网页入口 `/visitor/:sessionId` 与 `/m/tour/:sessionId` 共用响应式导览界面；微信小程序已移除，保留网页与 App。

## 1. 连续问答与可打断语音

- 会话分别保存实际游览位置和最近讨论的景点。游客站在长廊时可以询问十七孔桥，再追问“那它有多长”，不会把路线位置改到桥上。
- 对比“刚才那个景点”时解析两个对象；缺少上文时先澄清。新增事实问题优先使用对应 FAQ，不再用历史补充段覆盖长度等直接答案。
- 检索沿用景点/主题过滤、BM25、字符 TF-IDF 和 RRF，增加可审查的景区别名与口语同义词。这不是新部署的密集向量模型，也不称作知识图谱。
- 网页传 `defer_speech=true`，先获取已完成核对的文本，再请求本轮媒体。星云正常语速仍由原 SDK 播报；慢速/本地语音通过独立媒体接口合成。
- 生成、媒体请求和播放均可打断。客户端以轮次和播放版本拒绝迟到结果；服务端串行处理同会话上下文，并取消断开连接的协程。未完成的用户提问保留在可见记录中，但不混入下一轮模型历史。
- 每次答复记录文本准备时间和响应时间。这里没有逐字流式生成；正在执行的同步外部模型线程也不保证能撤销提供方计算。

## 2. 游览中的剩余路线调整

入口：顶部“调整行程”，或输入“孩子累了，只剩90分钟，从东门离园”。先显示预览，点击“确认调整路线”才写入。

- 时间、步行节奏、离园方向、跳过景点、额外预留可编辑；未提供剩余时间时要求填写，不默认猜一个小时。
- 保留已游览前缀和当前站，按原顺序筛选未游览景点，不突然加入新景点。
- 用现有 OSM 园内步行距离矩阵估算路程，计入后续停留、步行、休息、离园与预留。展示原方案与新方案成本，以及移除每个景点的原因。
- 较多台阶的已知景点在轻松模式中排除；不声称全程经过实测或保证轮椅通行。离园使用已核对景点作附近锚点并加5分钟，界面明确显示此近似。
- 方案是有时限的签名令牌，绑定会话、条件、景点目录和当前进度。确认时锁定路线/进度并重算；已过期、重复提交、路线变化或剩余时间不足时要求重算。导游身份和当前进度保持一致。
- 距离快照版本为 OSM-2026-10-10。无实时拥挤、封路、游船班次数据；不会把估算描述成实时导航。

## 3. 有时代边界的史料对话

在“对话角色”选择“乾隆时期·史料对话”。由当前数字导游进行明确标注的历史解说，未制作或冒充乾隆的真实影像、原声、原话。

- 历史叙事范围为1736—1795；1795是年号范围上限，并非乾隆去世年份。
- 第一批双语事实卡覆盖清漪园建园、命名、完工、长廊始建、十七孔桥始建与命名、西郊水利。不是对乾隆一生所有问题的开放式史料覆盖。
- 建园事实与来源、年代时间线、摘要版本一起显示。事实卡不会调用大模型补写未知细节。
- 1860年焚毁、1886年重建、1888年改名等后世事件标注“已交由现代导游”；当代设施问题交回现有受资料约束的现代问答。
- 私人思想、未收录的画师/造价等问题明确资料不足；不给虚构引语。新增史料应先核查具体事实与年代，再进入事实卡。

## 验证与重现

本次结果：70项Python测试、90项前端测试、23项真实接口检查通过；类型检查与生产构建通过。真实接口包含“名字→长度”连续追问、对比对象解析及游览进度变化后旧方案失效。以上是回归检查数量，不是问答准确率或比赛评分。

仓库根目录运行：`.venv/Scripts/python.exe -m unittest discover -s scripts/tests`。

前端目录运行：`node node_modules/vitest/vitest.mjs run --maxWorkers=1 --minWorkers=1`，并执行 `vue-tsc --build --force`、`vite build`。内存有限时分开执行，Node可加 `--max-old-space-size=1536`。

本机前后端和种子数据可用后运行：`.venv/Scripts/python.exe scripts/smoke_adaptive_tour.py`。脚本创建明确标记的测试会话，检查权限隔离、预览不写入、确认后保留进度、签名重放拒绝、历史边界、延后媒体及连续追问，最后结束自己的会话；不打印凭据。

另外通过浏览器验证了1280×720桌面和390×844窄屏下的角色切换、英文答复、路线确认，以及真实音频播放完成。构建原有的大包提示和Sass弃用提示仍存在。

外部服务实测限制：本次星云云端连接未成功，未将该部分记作通过；中文慢速语音在Edge TTS不可用时回落到本机男声并完成播放。英文云端语音、星云口型和第三方服务可用性需要在对应平台恢复后继续验收。
