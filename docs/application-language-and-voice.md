# 网页全局语言与数字人音色修复

## 使用方式

登录页、游客行程规划页、导览页和后台顶栏统一提供「中文 / English」开关。切换会同步导航、表单标签、按钮、弹窗、状态、日期、分页、图表、景点及路线展示。设置保存在本机浏览器，刷新及跨页面继续生效。手机浏览器页面也使用同一语言设置。

开关不会重新挂载表单或清空路线、昵称、当前站和已输入的问题。新问答按当前语言请求；已有聊天内容、用户输入、文档原文与证据摘录保留原文。编辑表单保留数据库原始值，切换语言不会把翻译写回数据库。外部地图栅格上的地名属于地图图片，不能通过界面词典翻译。本次范围是网页应用；微信小程序已移除。

`frontend/src/i18n/index.ts` 管理响应式语言、日期、参数和只读表格的显示转换；`en.json` 是本地词典，`overrides.en.json` 保存人工修订。语言切换无需额外调用大模型。`scripts/build_ui_english.py` 只用于开发时补全公共界面文案与公开景点展示词条，不发送账户配置、密钥、用户对话或审核原文。

## 景点详情漏翻修复（2026-10-15）

此前生成工具只采集景点名称、简介、城市、位置、季节与标签，漏掉 `history_detail`、`photo_tips`、`tour_tips` 和 `service_facilities`，导致英文详情混入中文。现已补齐本机 16 个景点的四类完整介绍，共新增 49 条去重后的英文词条；保留原文中的数字、事实限制和服务信息未核实说明。

生成工具默认从 `resources/summer-palace-content.zip` 收集公开词条，可额外检查运行中的数据库，避免资源包更新前遗漏新编辑内容：

```powershell
# 只检查覆盖率，不调用模型、不修改文件；有漏翻时以非零状态退出。
python scripts/build_ui_english.py --content-only --check --base-url http://127.0.0.1:8001
# 开发时补齐翻译，全部批次通过完整性检查后才写入正式词典。
python scripts/build_ui_english.py --content-only --base-url http://127.0.0.1:8001
```

词条按原始正文匹配，不依赖景点 ID；导入资源后 ID 变化仍可翻译。修改介绍正文后需再次检查并补齐词典。未知的管理员自写内容仍保留原文，不在游客打开详情时发起翻译请求。新增测试覆盖四类介绍的采集、数字与占位符保护、本机资源包全量英文覆盖，以及打开详情后的语言切换、中文恢复和路线选择保留。

## 慢速功能已移除（2026-10-16）

网页导览已删除慢速语音按钮、状态与请求参数。问答接口不再提供语速选项；旧客户端携带的 `speech_rate` 会被忽略，旧答复中的慢速元数据也不再影响后续音频生成。星云数字人统一使用平台应用的正常语音，本地音频使用所选音色、正常速度。正常播放、仅文字和语言切换仍保留。

下文记录此前问题的排查过程，不代表仍提供慢速功能。

## 模型请求退化修复（2026-10-16）

排查英文问答不可用时发现 `get_llm_res` 在请求线程内引用未声明的 `tour_mode`，导致调用 SDK 前抛出 `NameError`，而翻译层捕获异常后只返回通用英文不可用提示。现已增加明确的模式参数，并用统一的导览请求入口处理生成、检索问题翻译、答复翻译及证据审核。

同时修复可选供应商分支：真正使用已选择的客户端，JSON 格式重试保持同一供应商，请求结束或失败都关闭临时客户端。普通业务默认仍使用原模型；只有显式启用导览供应商配置时才切换。翻译失败日志记录异常类型，不记录密钥或请求正文。

验证包含 6 项真实请求函数回归测试、7 项语言策略测试，以及运行中接口的英文问候、长廊历史、下一站和中文长度问答。成功的历史回答来自 `deepseek-chat`；纯事实直答仍标记为数据库回答，不标记成模型生成。

## 历史排查：慢速为什么曾经变成女声

星云正常语音由其应用驱动，慢速另走本地 TTS。文轩的备用配置曾为女声，且旧女式 VRM 路径会影响音色判断。现在云数字人的备用语音遵从显式 `voice_style`，不再受旧 VRM 路径影响；本地 VRM/GLB 模型已下线，不再参与音色判断。

本机文轩（guide_id=37）的备用配置已修正为 `male_wenhou`。创建或配置星云数字人时可明确选择备用男声/女声。中文男声使用 Yunxi/Yunjian，英文男声使用 Guy/Christopher，慢速请求为 0.8（-20%）。星云正常模式使用原 SDK，服务端不再额外生成一段不用的 Edge 音频。

备用 TTS 与星云原声是不同引擎；这里保证性别匹配，不承诺声纹完全相同。慢速合成播放不驱动星云口型。

## 当前外部服务限制（2026-10-12 实测）

Edge-TTS 7.2.8 的男声、女声连接当前均返回 403。代理与直连都失败，不是音色修复造成的错误。Windows 上新增严格按性别和语言匹配的离线语音兜底，文字通过 JSON stdin 传递，不作为 PowerShell 命令。它不会安装音色或修改注册表、系统声音、代理和默认设备。

本机有中文男声 Kangkang，真实中文慢速接口生成并成功下载 511916 字节 WAV。本机没有英文男声音色，因此英文慢速本次没有生成音频。缺少匹配音色时不会替换成女声，网页保留答案并提示语音不可用。英文慢速恢复仍取决于外部服务恢复或部署匹配的英语男声合成服务；不能把单元测试中模拟的英文音频当成已完成实际播放。

## 验证

本轮 55 项后端、60 项前端测试通过；全项目类型检查与生产构建通过。构建仍有原有 Sass API 弃用及大包体提示。测试覆盖云音色、中文/英文男声及慢速映射、离线兜底拒绝错性别/错语言、无音频不回退到默认云声、全局语言持久化、输入与路线保留、日期和只读表格显示。

真实页面检查包括英文登录、后台导航/景点表格、游客地图/天气/路线卡片、数字人选择弹窗与完整导览。1440×900 导览没有横向溢出，数字人保持全身；中文切换与英文切回保留当前站和输入。真实接口验收创建并结束自己的测试会话，未改动游客已有会话。

验收日志与截图位于忽略目录 `work_dirs`，不包含密钥或登录 Token。前端入口 `http://127.0.0.1:5173/login`；后端端口 8000。
