# 启动、路网和问答检查（2026-11-06）

## 本次修改
- Windows 后端启动固定到项目根目录，使用同一 Python 启动 Uvicorn；保留显式配置的资源地址。
- 新增 `/health/live` 和 `/health/ready`。数据库断开、表结构异常或景点为空时，就绪探针返回 503；RAG 单独报告状态。Docker 就绪检测使用该探针。
- App 地址配置优先选择有默认路由的物理网卡，写入前检查后端就绪状态。多网卡场景仍可显式指定 `-ServerAddress`；离线构建可使用 `-SkipHealthCheck`。
- Web 普通请求设置超时；上传、索引重建、问答评测分别保留较长超时。
- 路网构建同时检查道路和节点的步行权限、锁闭与施工标记；运行时拒绝快照中标记为受限的道路。没有重画或杜撰通路。
- 问答评测除关键词外，增加切题性、逐段证据支持和引用原文核验；使用生成回答时的同一检索快照和实际截取片段。模型调用移出异步主循环，避免评测期间阻塞其他请求。
- 管理员评测表显示证据复核结果，失败时仍保留原回答供检查。

## 验证结果
- 36 项测试、107 个子测试通过；包含断库、空库、通行限制、引用截取、答非所问、动态信息缺失与跨景点追问。
- Web 类型检查及生产打包通过；打包产物位于电脑临时目录，未发布到 GitHub。
- 当前服务就绪探针：数据库 connected，16 个景点，RAG available。
- 路网：1188 节点、1270 边、19 个景点/园门接入点、171 组连接均可达；几何与距离检查无异常。
- 乐寿堂展示点距道路接入点 33.7 米，列入人工现场核查清单；不能凭最近道路投影认定真实入口。
- 真实云模型抽测仅 3 题：2 题通过，亲子轻松线问题 1 题未通过证据/相关性检查。该结果不是完整题库准确率；未降低阈值或改写题库以消除失败。

## 使用
```powershell
.\start_backend.ps1
Invoke-RestMethod http://127.0.0.1:18000/health/ready
.\scripts\configure_app.ps1 -ServerAddress http://电脑局域网IP:18000
python scripts/audit_walk_network.py docs/walk-network-audit.json
```
空库按 README 导入公开内容包；已有数据不重复导入。App 地址变更后需要重新编译同步手机。

## 边界
路网检查基于现有 OSM 快照和封闭规则，未新增现场测绘或实时封路数据。节点权限新规则在重新构建路网时生效，现有快照无法补出未记录的节点属性。模型证据复核仍可能误判，不等于独立人工核验。未改动音频播放、跨端领取流程或交付安全模块。
