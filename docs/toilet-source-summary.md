## 当前能得出的结论

- 颐和园：有两条带码头参照物的具体方位线索；尚未核对原PDF表格，不能直接上线为导航点。北京市政府还介绍过官方公众号“颐和导览”的厕所查询功能。
- 故宫：有两处明确名称和方位，但来源年代较早，必须再确认设施现状。
- 九寨沟：诺日朗瀑布厕所出现在官方维修公告中，公告不能证明维修完成或已开放。
- 黄山：始信峰公厕出现在2026年工作计划中，归入建设线索，不算已开放设施。
- 无锡灵山、拈花湾、杭州西湖及其余景区：目前未整理到足以支持精确导航的官方点位。

## 项目使用规则

1. 保留原始链接、资料日期和核查日期；园区级资料不自动归属到每个子景点。
2. 坐标没有证据就留空；当前开放状态统一为未知，不能显示“营业中”。
3. 没有坐标与路网依据，不计算用户到厕所的距离，也不推荐“最近厕所”。
4. 只有完成原文复核、坐标及坐标系确认后，才进入数据库设施表并由接口提供。
5. 查询不到时，可引导用户查看官方导览或询问现场工作人员，不让模型补造位置。

## 后续核实顺序

先补颐和园原始检查表与官方导览点位，再确认故宫现行地图、九寨沟维修后的状态；随后补无锡与其他目的地。北京市公共数据目录有公厕坐标和使用状态字段，但尚未读取明细，不能当作已取得点位。

结构化证据：`data/official_toilet_evidence.json`；总来源库：`data/official_travel_sources.json`。两者均已复制到资源包。当前尚未接入数据库/API，未 push。
