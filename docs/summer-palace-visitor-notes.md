# 颐和园景区游览说明

## 景区概况

颐和园位于北京市海淀区，是以万寿山、昆明湖为主体的大型皇家园林。园林将北方皇家建筑的秩序感与江南山水园林的借景、对景手法相结合，适合历史文化、古建筑、园林艺术、湖景摄影和亲子研学等主题游览。

## 核心景点

### 仁寿殿

仁寿殿位于东宫门内，是颐和园东部宫廷区的重要建筑，主要承担处理政务和接见活动等功能。游览时可重点观察殿前陈设、院落尺度，以及宫廷区向山水园林过渡的空间关系。

### 长廊

长廊沿昆明湖北岸展开，将多处园林建筑和湖山景观连接起来。梁枋绘画包含山水、花鸟、人物故事等题材，既能遮阳避雨，也是体验“移步换景”的重要空间。拍摄时可利用连续廊柱形成纵深透视，并注意避让正常游览人流。

### 佛香阁与万寿山

佛香阁位于万寿山前山中部，是颐和园重要的标志性建筑。建筑依山势层层抬升，从湖面和长廊均能形成清晰对景。登临区域可观察昆明湖与园林总体格局，但台阶较多，应根据同行人员体力决定是否登高。

### 昆明湖

昆明湖是颐和园山水格局的核心水体，与万寿山共同构成开阔的湖山景观。湖岸、堤岛、桥梁与远近建筑形成多层次视线关系。春秋两季光线和能见度较好，适合散步与摄影；临水游览时应遵守安全提示。

### 十七孔桥

十七孔桥连接东堤与南湖岛，是昆明湖区域的重要景观桥梁。桥体的连续券洞、石栏与水面倒影形成富有节奏的构图。建议从侧向机位拍摄桥洞和桥身曲线，傍晚柔和光线更适合表现石桥轮廓。

### 苏州街

苏州街位于万寿山后山后湖区域，沿水岸布置店铺式建筑，以桥、水、街共同营造江南水镇意象。它与前山开阔庄重的皇家园林景观形成鲜明对比，适合亲子观察和情景化摄影。

## 推荐路线

- 经典文化线：东宫门—仁寿殿—长廊—佛香阁，约 100 分钟。
- 湖畔风光线：长廊—昆明湖—十七孔桥，约 90 分钟。
- 亲子轻松线：苏州街—长廊—昆明湖，约 80 分钟。

60 分钟以内可选择仁寿殿、长廊等靠近东部入口的景点；90 至 120 分钟可增加佛香阁或昆明湖湖岸游览；150 分钟以上可组合前山、湖区和后山苏州街，形成较完整的园林空间体验。

## 安全与亲子提示

湖岸和平缓区域更适合亲子和轻松游览。湖边、山路及佛香阁区域存在台阶和坡道，雨雪天气注意防滑；夏季注意防晒补水，冬季留意湖面结冰区域的安全提示。带儿童游览时建议控制单个景点停留时长，可围绕建筑彩画、桥梁结构和湖山视线开展观察互动。

## 智能导览服务

系统可依据历史、自然、摄影和亲子体验等游客偏好推荐景点，并在游客进入景点触发半径后自动显示对应讲解。游客还可通过文字或语音询问景点历史、建筑特色、游览时长、服务设施和拍摄建议。
