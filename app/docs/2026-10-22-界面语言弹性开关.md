# 界面语言：弹性滑动开关

2026-10-22。范围：`app/pages/mine/mine.vue` 的「我的 → 界面语言」；语言切换逻辑本身未改。

## 效果

- 原来的两个独立按钮改成标准分段开关：白色滑块（`.lang-thumb`）在「中文 / English」之间滑动，`transition: transform 460ms cubic-bezier(.34,1.56,.64,1)`，到位时带轻微过冲回弹，形成弹性手感。
- 两个选项等宽（115rpx），滑块 115×59rpx，容器内边距 8rpx；整体宽度与改动前基本一致（约 246rpx），文字居中。激活项为深紫色加粗，未激活为灰色，颜色有 260ms 过渡。
- 按下选项时按钮 `scale(.88)`、松手弹回（`hover-class="lang-press"` + 弹性 `transition`），同时不再出现 uni-app 默认的灰色按压底。
- `prefers-reduced-motion: reduce` 时关闭滑块与按钮过渡。
- 切换仍走 `setTourLanguage`，写入 `zhiyou.app-language` 并让全局 `tourLanguage` 立即刷新，页面文案与其它 Tab 同步。
