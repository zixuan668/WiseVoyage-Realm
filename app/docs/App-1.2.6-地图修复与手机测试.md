# 智游知境 App 1.2.6：路线地图修复与测试

## 修改范围与原因

只修改 `app/`。main 的 Web、后端及数据库结构没有改动；没有合并或切换 LZX 分支。
main 基准是 `d31183cf5bd3ca9948d1c7fbf85b091a91368ee8`，只读对照 LZX `d3d35cd0f0bcbe41b7c091aee5723c3908fb8fae` 的路线地图。

上一版把原生 `<map>` 放入滚动弹层，原生地图会独立叠层，滚动时遮住地点名。它无法靠提高文字的 z-index 解决，见 [uni-app 原生组件限制](https://uniapp.dcloud.net.cn/component/native-component)。

## 本次修复与优化

- 行前“路线与用时”、途中“剩余游览路线”和调整方案预览统一使用 DOM 地图，与文字一起滚动、裁剪；移除弹层里的原生地图。
- 保留高德底图，使用与 Web 一致的 Leaflet 1.9.4；脚本、样式及许可证随 App 打包，不依赖运行时 CDN 下载地图组件。
- 对齐 Web 圆角路线、选中路段深紫高亮、其他路段浅紫、调整前灰色、景点编号和当前站绿色标记；可点路线或路段按钮查看距离与用时。
- 地图高度改为约屏幕高度的 38%（260–340 px），按全部步道转折点、景点及入口/出口自动框选，保留边距。双指缩放、拖动后可点“显示完整路线”归位。无步道数据时不编造直线。
- 修复连续点击放大与归位的缩放动画冲突；选择另一条路段时保留手动缩放；关闭弹层释放地图，重新打开不会保留旧图层。
- 新调整方案生成后重置“调整前”及旧路段选择，避免显示上一个方案的比较状态。
- 修复“不要跳过下一站 / Don't skip the next stop”被反向识别成跳站请求；明确离园请求可以正常打开调整入口。
- 新交互文案支持中英文。

## 手机测试步骤

1. 安装 **1.2.6**，可覆盖此前同签名的智游知境。可在 Android 设置 → 应用 → 智游知境中核对版本。手机与电脑连接同一 Wi-Fi，电脑后端保持运行；本包使用 `http://192.168.43.41:18000`。
2. **行前路线**：进入“智能导览 → 游览路线”，选择北京同一景区的 3–4 个景点，在“我的行程”测试上移、下移、移除和重新选入。顺序和编号要同步变化，用时以重新计算结果为准；某些对称路线的用时可能相同。点“路线与用时”，检查初始整条路线可见、编号清楚、没有拉直替代缺失道路。
3. **个性化入口**：切换“个性化”，选导游、偏好和可用时长，生成路线，再开始导览。点顶部“路线与用时”，出现“剩余游览路线”。从地图下方的文字区反复上下滑动，地点名应正常出现，地图应跟随内容滚动并被弹层边界裁剪。地图内部用拖动平移、双指缩放；点“显示完整路线”后应重新看见完整路线及所有景点。关闭重开再重复一次。
4. **途中调整**：关闭详情，点“调整行程”，分别测试“时间不够了”“想少走路”“跳过下一站”“准备离园”。每次先生成方案；点“调整前 / 调整后”对比路线、编号和用时，滚动检查地点名。只生成预览时实际行程不能变化；点“采用此方案”后，顶部行程及剩余路线才更新。
5. **异常条件**：生成方案后修改时间，旧方案的“采用”应禁用；重新生成才可使用。要测试不可行方案，可设剩余 **1 分钟**，并在“保留景点与通行条件”中将一个未游览景点设为必游；不应允许采用。不要仅凭“1 分钟离园”判断失败，因为用户恰好已在出口附近时可能可行。
6. **否定与语言**：在导览文字输入“不要跳过下一站”，不应自动选中跳站；输入“准备离园”应进入调整流程。切换 English 后检查详情、缩放提示、归位按钮和调整面板文案。

若出现问题，请记录入口、语言、所选景点顺序和屏幕现象；“底图加载失败，路线仍可查看”表示底图网络失败，已有路线和编号仍应可见，可点重试。
