# 引导页：跳过与「开始体验」动效

2026-10-21。范围：`app/pages/onboarding/onboarding.vue` 与 `app/tests/onboarding.test.cjs`；不改后端、其他页面和 Web 端。

## 背景

引导页页头左上角的品牌字已按用户要求删除，只剩右上角「跳过」；第 3 页底部是「开始体验」。

## 交互

- **跳过**：点「跳过」后，文字向上抬升并淡出（260ms，`.is-skipping`），登录页以跳过按钮的中心为 `transform-origin` 弹出（沿用 `loginSpring` 弹性动画），约 1s 后进入登录路由。
- **开始体验**：按钮为长方形圆角样式（宽 100%、高 100rpx、圆角 30rpx、紫色 `#6750d9`、白字、柔和投影）。按住时只做轻微缩小（scale .95），**不变浅、不变色、不透明**：按钮加了 `hover-class="none"`、去掉 `:active` 变色样式并关闭点击高亮（`-webkit-tap-highlight-color: transparent`）。松手瞬间按钮消失、从按钮表面生成 26×6 = 156 个小圆点散开（620ms），随后登录页从按钮中心弹出，约 1.35s 后进入登录路由。缩小由 `@touchstart` / `@touchend` 控制，所以按住多久就一直缩着，抬手才散。
- 两条路径都会先写入引导完成标记；写入失败时停留在引导页并提示。

## 验证

- 真机 23116PN5BC（412×898、DPR 2.625、HBuilder 基座）通过 WebView CDP 触摸事件验证按住/松手：按下 320ms 时 `.is-pressing` 生效、transform 为 scale(0.95)、按钮背景仍为 rgb(103,80,217)、opacity 1，按钮中心像素与静止时相差 ≤1（没有变浅）；抬手后立刻生成 156 个 `.burst-particle`、按钮 opacity 归 0，约 1.35s 跳转登录。松手前粒子数为 0。序列帧见 `work_dirs/onboarding/cta-sequence.png`，按住/松手对比见 `press-idle.png`、`press-held.png`、`press-released.png`。
- 跳过：约 60ms 时 `.is-skipping` 生效、跳过按钮上移且透明度 0.78；约 300ms 时登录页 `transform-origin` 落在右上角跳过按钮中心 (367.9, 78.8)。
- `node --test tests/*.test.cjs`：57 项通过，含新增的跳过动画与「先缩小后散点」断言。

## 英文欢迎页（2026-10-22 追加）

欢迎页右上角最右侧是一个圆形语言按钮，「跳过」在它左边：中文界面显示 `ENG`（点击进英文），英文界面显示 `中`（点击回中文）。点击后三屏标题、跳过按钮、开始体验文案即时切换，并把 `zhiyou.app-language` 写入本机；下次启动欢迎页直接按该语言显示。页面 `onLoad` 仍从存储读取语言，内嵌的登录页组件也会跟随（实测英文下为 Every journey has a story / Nickname / Password / Sign in）。

## 开始体验：玻璃按钮与散点动效（2026-10-22 追加）

按钮从实心紫改为玻璃质感：近纯白的玻璃底（竖向极浅渐变，保证颜色均匀）+ 1rpx 白色描边 + 顶部高光层（`.cta-gloss`）+ 柔和紫色光晕（`.cta-sheen` 用径向渐变、8px 模糊，左右缓慢漂移；早期版本是旋转的线性光带，会留下一条可见的斜向明暗分界，已替换）+ 内高光与外投影（`box-shadow` 三层，配 `.cta-float` 的 4.6s 轻微上下浮动）。文字为深紫 `#6750d9`，没有按下变色。

点击行为不变：按住时 `.is-pressing` 只把按钮缩到 `.95`；松手时 `.is-bursting` 用 110deg 的遮罩把按钮在 260ms 内擦掉，同时从按钮表面生成 26×6 = 156 个圆点，尺寸 2.4–9.4px、五种紫色（#6750d9 / #8f7ce8 / #ae9bf0 / #c9bcf5 / #e0d8fb），并按擦除方向依次延迟 0–196ms 散开（620ms），随后登录页从按钮中心弹出。

真机（412×898 @2.625）验证：静止时按钮为白色玻璃渐变，流光层 transform 在两次截图间移动；按住 320ms 时 transform 为 scale(0.95)、opacity 1、无粒子；松手后逐帧可见按钮被擦掉、大小不一的紫色圆点铺满按钮区域并散开，约 1.35s 进入登录。截图见 `glass-final-a.png`、`glass-sequence2.png`、`glass-device-held.png`。

## 圆点从文字位置散开（2026-10-22 追加）

按反馈，圆点消散不再从整个按钮矩形开始：`release()` 改为查询 `.cta-label` 的矩形，`makeParticles()` 以该矩形为采样范围（18×4 = 72 个点，尺寸 1.6–7.1px，五种紫色，延迟 0–172ms），按钮中心只用于登录页弹出的原点。

真机（412×898 @2.625）实测：按钮 337×54.9px，文字 74.7×23.8px、起点 x=168.6；松手后 120ms 生成 72 个 `.burst-particle`，粒子初始范围集中在文字附近（x 约 123–242），不再铺满 39–373px 的整条按钮；逐帧序列见 `work_dirs/onboarding/text-dissolve-sequence.png`。

## 边界

- 时序集中在 `holdStart` / `holdEnd` / `release` / `skipIntro` 内，散点样式在 `.burst-particle`，方便继续调节时长与密度。
- 离开动画开始时 `leaving` 为真，会让「跳过」和分页圆点变成 disabled；uni-app 的 `uni-button[disabled]` 默认是 #f7f7f7 灰底，因此补了 `.skip[disabled]`、`.dot-target[disabled]` 的透明底覆盖，避免动效中闪出浅色块。
- 登录页仍是真实的 `AuthPage` 组件，没有用占位图；引导完成标记沿用 `zhiyou.onboarding.v1.completed`。

## 开始体验：去掉白色底，直接露出背景（2026-10-22 追加）

按反馈，按钮不再有白色玻璃底：`.continue-button` 的背景改为透明，删除白色填充、描边、内高光/外投影和 `backdrop-filter`，同时移除只服务于玻璃面的 `.cta-gloss`、`.cta-sheen` 两层及 `ctaSweep` 动画。按钮区域直接显示引导页背景渐变，按住时只有文字轻微缩小；松手时文字被遮罩擦掉、紫色圆点从背景上散开，再弹出登录页，全程不再出现白色按钮底。
