# App 行程流程与导览评分

基于 main `03bd19f425efa3496631dd58bb2ccd592ffa76db`。

## 保留的 App 功能

- 首页仅显示“游览路线”；查看行程后进入个性化行程，可返回继续选择，保留景点顺序、数字人选择及滚动位置。
- 个性化行程可查看路线与用时、选择数字人并开始导览。
- 导览输入栏增加 64rpx 与底部安全区留白，键盘弹起时保留 12rpx 内边距。
- 结束导览先确认，待结束接口成功后进入记录页；失败可以重试。
- 已结束的导览支持 1–5 星评分，按账号与导览 ID 保存；“我的 → 游览记录”显示评分并支持进入修改，返回列表后更新。
- 删除评分页底部存储说明，成功提示为“评分已保存”；新增界面包含英文文案。
- 保持既有评分存储键，覆盖安装可读取此前本机评分；评分没有上传服务器。

## 数字人代码回退

用户于 2026-10-20 明确要求撤回数字人修改。导览、聊天语音组件及对应 SDK 测试已逐字节恢复到上述 main 基准，撤回包内固定 SDK 接入与 `prefer-hardware` 配置，移除本次新增的解码发包检查脚本及接入说明。

回退后恢复 main 的 API 提供 SDK 加载方式，之前 Android 软解码错误 10005 可能重现；已向用户说明。本次仅回退代码，保留本地数据库的新人物绑定与此前同步的 LZX 资料，不提交凭据或本地数据库。

## 验证与交付边界

- 路线、评分、历史列表和原版 SDK 的 27 项回归检查。
- App 编译后的界面测试覆盖行程往返、模拟键盘高度、真实结束状态响应、评分保存、历史列表读取和修改后返回刷新；历史列表接口使用模拟数据，不代表真机验证。
- 数字人组件与 main 基准的精确比较；Web、后端及数字人源码相对该基准无本次修改。
- 源码版本 1.4.4（144）用于区分数字人回退后的版本；本次提交不提供或替换 APK，已下载的 1.4.3 安装包不会随 Git 推送改变。

用户账号、导览记录和人物绑定属于本地数据库内容，不随 GitHub 分支推送同步。LZX 资料同步另有本机备份与验证记录。
