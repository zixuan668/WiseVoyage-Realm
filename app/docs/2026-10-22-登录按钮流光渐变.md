# 登录按钮：紫色流光渐变

2026-10-22。范围：`app/pages/auth/auth.vue`。只改登录主按钮（登录 / 注册并登录），弹窗里的「确定」等其它 `.primary` 按钮不变。

## 效果

- 登录按钮保留原高度 96rpx、圆角 22rpx、白字和 `.primary[disabled]` 逻辑，新增 `.login-cta`：
  - 底色为 `linear-gradient(110deg, #4527d8 → #5b3bf0 → #7d5dff → #b49cff → #7d5dff → #5b3bf0 → #4527d8)` 的紫色渐变；
  - `background-size: 220% 100%`，用 `5.6s ease-in-out infinite alternate` 来回移动 `background-position`，让亮带缓慢扫过，形成流光感；
  - 投影换成紫色 `rgba(88,58,240,.5)`。
- 登录中（`disabled`）恢复灰色 `#e2e8f0`，取消动画；`prefers-reduced-motion: reduce` 时停在渐变中段不动。
- 选择器用 `.primary.login-cta`：uni-app 编译时会合并重复的 `.primary` 规则并把这个合并后的规则排到后面，只用 `.login-cta` 会被 `.primary` 的 `background` 盖掉（表现为按钮仍是纯色）。

## 验证

`node --test app/tests/*.test.cjs` → 61 项通过（纯样式与模板 class 改动，不影响逻辑）。

真机检查：`.login-cta` 计算样式为 `background-image: linear-gradient(...)`、`background-size: 220% 100%`，`animation-name: loginFlow`，`background-position` 两次采样从 86.3% 变到 96.8%，流光在动。

## 2026-10-22 追加：登录页语言切换改为圆形按钮

按用户提供的样式图，登录页右上角的「中文 / English」胶囊切换（`.auth-language`）换成和引导页一致的白色圆形按钮（`.auth-lang`，64rpx 圆、白底、紫色 ENG / 中）：中文界面显示 `ENG`（点击切英文），英文界面显示 `中`（点击切回中文），带 `aria-pressed` 和切换提示。
