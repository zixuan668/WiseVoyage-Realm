# AI 页标签栏直接收起

2026-10-22。范围：`app/pages/tabs/tabs.vue`、`app/components/TabDock.vue`、`app/App.vue` 与 `app/tests/tab-dock.test.cjs`；不改页面切换动画本身。

## 行为

- 切到「AI小导游」页时，底部 Tab 栏在切换瞬间整条消失（不下滑、不缩小、不淡出）。
- 离开 AI 页时，Tab 栏在切换瞬间整条出现，之后保持不动。
- **滑动页面过程中 Tab 栏不参与任何上下动画**：不会跟随页面进度往下收、也不会往上回；普通页（智能导览 ↔ 我的）之间滑动时它始终原地不动。
- 页面切换效果保持不变：三页仍在同一个 translate 轨道里左右滑动，沿用原来的 420ms 过冲缓动（点标签 1.16、松手吸附 1.06）。
- 键盘弹起、导览行程面板打开导致的隐藏仍沿用原来的 `hidden` 逻辑（也是瞬时切换）。

## 实现

- `tabs.vue` 的 `aiHidden` 只在 `selectTab` / `settle` 提交切换时同步更新：目标是 AI 则为 true，否则为 false；不存在延迟或按进度计算的定时器。
- `TabDock.hideAmount` 只看 `aiHidden || hidden`，不再依赖 `progress`；隐藏态的 `transform`/`opacity` 是内联样式瞬时值，没有过渡，所以滑动过程中样式保持不变。
- `dock-down` 类跟随 `aiHidden`；`App.vue` 去掉该状态下 `padding-bottom` 的 `.32s` 过渡。
- `selectTab` / `settle` / `animateProgress` 的页面动画未改动。

## 验证

```powershell
node --test app/tests/tab-dock.test.cjs
node --test app/tests/*.test.cjs
```

61 项全部通过。真机 CDP 记录（AI→我的，412×898）：松手时刻 t=22577，`.dock` 只在 t=22644 发生一次 `translate3d(0,108%,0)` → `translate3d(0,0%,0)` 的瞬切，之后整个滑动过程不再有任何变化；`.sk-wrap` 始终为 0。
